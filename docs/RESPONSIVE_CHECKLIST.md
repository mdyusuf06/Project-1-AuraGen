# Responsive Design Testing Checklist

**Author:** Raksha R. (Senior Frontend Lead)  
**Scope:** Mobile, Tablet & Desktop Viewports

---

## Viewport Quality Checklist

- [x] **Mobile Portrait (320px - 480px):**
  - Form inputs stack vertically in a single column.
  - Stepper navigation buttons scale to full width.
  - Telemetry HUD collapses to compact mobile drawer.
- [x] **Mobile Landscape (481px - 767px):**
  - Side-by-side inputs for currency and phone fields.
  - Gauge dial adjusts to 160px diameter.
- [x] **Tablet Portrait (768px - 1023px):**
  - Two-column balanced form layout.
  - Floating top navigation bar with live WebSocket indicator.
- [x] **Desktop (1024px+):**
  - Full three-column financial form cards.
  - Interactive Telemetry Cockpit with real-time polyline chart.
